Self-improving skills

Explore and improve skills as you go.

Aitor Skills is a Codex and Claude-first library that tracks usage, summarizes behavior, and upgrades workflows through human-approved proposals. It is designed to evolve without leaking prompts or user data.

Live loop

Track -> Summarize -> Propose -> Approve. No silent edits.

Logs are metadata only. No prompts. No user text. No secrets.

Philosophy

The system treats skills as living protocols, not static snippets. Over time, the weekly feedback loop compounds: usage data reveals what actually works, highlights missing workflows, and surfaces opportunities to simplify. That evidence drives pruning, consolidation, and targeted upgrades so the library grows smarter without growing noisy. AGENTS.md sets the shared operating contract; SKILL.md files encode specialized workflows. With a human in the loop, the summarizer becomes a safe proposal engine that turns real usage into better skills and, eventually, new ones.

Self-improvement loop
Step 01

Track usage

Daily JSONL telemetry with minimal metadata and zero user content.

Step 02

Summarize

Generate JSON + HTML upkeep cards for quick human review.

Step 03

Propose

Conservative changes only. No auto-edits without approval.

Step 04

Approve

Branch-first edits and explicit go/no-go gates.

Security posture
  • Logs are data, never re-injected into prompts.
  • No prompts, user text, file contents, secrets, or PII.
  • Logging, summarization, and updates are separate steps.
  • Human approval required for skill edits.
  • Branch workflow for any skill change.
  • Future: integrity hashing and retention pruning.
